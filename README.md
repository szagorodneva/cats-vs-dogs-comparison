Interactive comparison app built with Python and Streamlit
# Cats vs Dogs Comparison

Интерактивное приложение для сравнения кошек и собак по списку критериев с указанием бизнес- и технических требований. 

## Зачем создан проект

Проект демонстрирует универсальный подход к представлению сложного сравнительного исследования в виде понятного интерактивного интерфейса.

Идея интерфейса возникла при работе над реальной коммерческой аналитической задачей под NDA. Исходные требования, данные, компании и выводы в этом репозитории не используются. Сравнение кошек и собак — полностью самостоятельный демонстрационный пример. Демонстрирую на реальных данных, можно применять =)

## Что показывает проект

- хранение сравнительной матрицы в Excel;
- загрузку и обработку данных с помощью Pandas;
- создание интерактивного интерфейса на Streamlit;
- отделение данных от логики приложения;
- возможность использовать тот же код с другой таблицей аналогичной структуры.

## Технологии
